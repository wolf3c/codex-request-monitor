# v0.2.0-beta

macOS 公开测试版 / macOS public beta.

## 更新 / Changes

- 中英文面板与独立的中英文 README，中文为仓库默认首页。
  Bilingual dashboard and separate Chinese and English READMEs, with Chinese as the repository default.
- 显示最近一次请求日志中的模型 ID；它不证明服务端实际执行了哪个模型。
  Show the latest request's logged model ID, without claiming to identify the model actually executed by the server.
- 增量状态只使用最近一次请求的明确日志证据；证据不足显示 `-`，避免沿用旧请求状态。
  Use explicit evidence for the latest request's incremental state; show `-` when evidence is insufficient.
- 增加可复制的 Codex 安装提示词、连接重试原理、功能图和 MIT 协议。
  Add a copyable installation prompt, connection retry explanation, overview graphics, and MIT license.

## 安装 / Install

```sh
codex plugin marketplace add wolf3c/codex-request-monitor --ref v0.2.0-beta
codex plugin add codex-request-monitor@codex-request-monitor-marketplace
```

[中文安装说明](https://github.com/wolf3c/codex-request-monitor/blob/v0.2.0-beta/README.md#安装与使用) · [English installation guide](https://github.com/wolf3c/codex-request-monitor/blob/v0.2.0-beta/README.en.md#install-and-use)

ZIP 包用于本机独立运行或手动检查；桌面插件安装请使用上方命令或 README 中的桌面安装步骤。
The ZIP supports standalone local use or manual inspection; install the desktop plugin using the commands above or the desktop instructions in the README.

## 验证与限制 / Validation and limitations

- 发布检查：Python 单元测试、独立配置的 CLI 安装、MCP 资源及合成诊断数据检查；ZIP 包随附 SHA-256 校验文件。
  Release checks: Python unit tests, isolated CLI installation, MCP resource and synthetic diagnostics checks; the ZIP includes a companion SHA-256 checksum file.
- 需要 macOS、Python 3.9+ 和支持 `codex plugin` 的 Codex 桌面版 / CLI；诊断日志兼容性取决于 Codex 版本。
  Requires macOS, Python 3.9+, and a Codex desktop/CLI version supporting `codex plugin`; diagnostics depend on the Codex version.
- 仅在本机只读处理。归档 / 恢复由用户手动执行，可能中断会话及子任务；不保证恢复 WebSocket。
  Local, read-only monitoring. Archive/restore is manual, may interrupt chats and subtasks, and does not guarantee WebSocket recovery.
