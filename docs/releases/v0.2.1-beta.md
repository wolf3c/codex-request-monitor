# v0.2.1-beta

macOS 公开测试版 / macOS public beta.

## 更新 / Changes

- 点击会话标题直接跳转到对应 Codex 对话；悬停或键盘聚焦时显示下划线和外链图标。左侧箭头继续用于展开 / 收起明细。
  Open a Codex chat directly from its session title. Hover or keyboard focus reveals an underline and external-link icon; the left arrow expands or collapses details.
- 手动重试指南弹窗增加「打开对话」，网页和侧栏共用会话 ID 校验与跳转逻辑。
  Add “Open chat” to the manual retry guide, with validated chat links in both browser and sidebar views.
- 修复自动刷新替换标题行后，较慢返回的跳转失败提示无法显示的问题。
  Keep delayed navigation errors visible when polling replaces a title row.
- 中英文说明同步更新。新增跳转协议、无效链接、断开连接与刷新竞态回归测试。
  Update both READMEs and add regression coverage for host navigation, invalid links, disconnected widgets, and polling races.

## 安装 / Install

```sh
codex plugin marketplace add wolf3c/codex-request-monitor --ref v0.2.1-beta
codex plugin add codex-request-monitor@codex-request-monitor-marketplace
```

[中文安装说明](https://github.com/wolf3c/codex-request-monitor/blob/v0.2.1-beta/README.md#安装与使用) · [English installation guide](https://github.com/wolf3c/codex-request-monitor/blob/v0.2.1-beta/README.en.md#install-and-use)

ZIP 可独立运行或用于手动检查；桌面插件请按上方命令或 README 安装。
The ZIP supports standalone local use or manual inspection; use the commands above or the README to install the desktop plugin.

## 验证与限制 / Validation and limitations

- 7 项 Python 测试、4 项 JavaScript 测试，以及独立配置的 CLI 安装和 MCP 资源检查。发布 ZIP 附带 `SHA256SUMS` 校验文件。
  Seven Python tests, four JavaScript tests, isolated CLI installation, and MCP resource checks. The release provides a companion `SHA256SUMS` file.
- 需要 macOS、Python 3.9+ 和支持 `codex plugin` 的 Codex 桌面版 / CLI。浏览器可能要求确认打开 Codex；侧栏是否允许跳转取决于宿主版本。
  Requires macOS, Python 3.9+, and a Codex desktop/CLI supporting `codex plugin`. Browsers may ask to open Codex; sidebar navigation depends on host support.
- 跳转不会归档对话或发送消息；归档 / 恢复仍由用户手动执行，也不保证恢复 WebSocket。
  Navigation does not archive chats or send messages. Archive/restore remains manual and does not guarantee WebSocket recovery.
