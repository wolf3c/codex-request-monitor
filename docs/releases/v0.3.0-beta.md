# v0.3.0-beta

macOS 公开测试版 / macOS public beta.

## 更新 / Changes

- 自动检查 Codex 代理配置、本地代理端口、系统代理和 TUN；核对进程连接与 Clash/Mihomo 记录，按证据显示代理已生效、未生效或待确认。
  Automatically inspect Codex proxy configuration, local ports, system proxy settings, and TUN interfaces. Match live sockets with Clash/Mihomo records to show confirmed proxy, confirmed direct, or pending status.
- 新增临时代理启动：仅启动已完全退出的 Codex，代理变量只对本次进程生效，不修改 `.env`、Shell 或系统代理配置。
  Launch an already-stopped Codex with process-scoped proxy variables, without editing `.env`, shell settings, or system proxy configuration.
- 网络与代理成为独立模块；近 5 分钟提醒收为「会话记录」旁的按钮，点击筛选，再次点击恢复。24 小时统计移到表格下方。
  Separate network controls from sessions, move recent alerts into a compact toggle filter, and place 24-hour statistics below the table.
- 新增「系统通知：开 / 关」，记住选择并同步同地址页面；关闭后页面提醒保留。较晚返回的授权结果不会覆盖较新的选择。
  Add persistent On/Off notification controls synchronized across same-origin pages. In-page alerts remain active when system notifications are off, and stale permission results cannot override newer choices.
- 补强跨进程启动互斥、控制接口读取时限，以及读取失败时切换分类的状态显示。中英文界面和安装说明同步更新。
  Guard launches across monitor processes, bound controller reads, preserve failed-read status during filtering, and update both languages.

## 安装 / Install

```sh
codex plugin marketplace add wolf3c/codex-request-monitor --ref v0.3.0-beta
codex plugin add codex-request-monitor@codex-request-monitor-marketplace
```

The ZIP supports standalone local use or manual inspection. Install the desktop plugin using the commands above or the README. A companion `SHA256SUMS` file verifies the ZIP.

## 验证与限制 / Validation and limitations

- 42 项 Python 测试、13 项 JavaScript 测试，以及隔离配置下的 CLI 安装、MCP 资源和合成日志检查；网页中英文、窄屏、筛选、明细和通知开关已验证。
  Validated with 42 Python tests, 13 JavaScript tests, isolated CLI installation, MCP resources, synthetic logs, and browser checks covering both languages, narrow screens, filters, details, and notification controls.
- 实际路由判定依赖可读取的本地 Clash/Mihomo Unix 接口和活跃的 Codex 服务连接。证据不足显示待确认，不代表全部对话均经代理，也不证明 WebSocket 或增量传输正常。
  Observed routes require a readable local Clash/Mihomo Unix API and active Codex service sockets. Insufficient evidence remains pending; it does not establish the route of every chat, WebSocket recovery, or incremental transfer.
- 应用或后台进程仍运行、状态无法确认、已有 `.env` 或启动条件不满足时禁止启动。真实 Codex 未因本次发布而重启；启动验证使用隔离程序，不代表所有机器上的真实应用启动验收。
  Launch is blocked while Codex or its background processes are running, state is unknown, an `.env` file exists, or other conditions are unmet. This release did not restart the real Codex app; isolated launch tests do not establish real-app launch acceptance on every machine.
- 更新后若旧宿主仍缓存工具列表，新诊断入口可能需要在当前任务结束后重新打开 Codex。安装本身不保证现有插件进程立即更新。
  A host caching the old tool catalog may need to reopen Codex after active work finishes. Installation does not guarantee an immediate update of existing plugin processes.
